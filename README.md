# carto-cegit-map

Maquette interactive d'un portail cartographique pour les collectivités territoriales sénégalaises (communes, villes, départements), conçue par [CEGIT](https://cegitgroup.com/fr).

Les cartes sont organisées par thème et rattachées aux compétences des collectivités définies par le Code général des collectivités territoriales (CGCT).

## Fonctionnalités de la maquette

- Accueil avec recherche, filtres par thème et accès grand public / agents et élus
- 47 cartes réparties en 10 thèmes, chacune rattachée à un article du CGCT
- Visionneuse : couches activables, zoom et déplacement, fiche d'information, mesure de distance
- Catalogue de données (onglet « Données »), inspiré de GeoNetwork : recherche plein texte, filtres à facettes, fiches de métadonnées ISO 19115 avec dictionnaire des attributs, services OGC et export XML ISO 19139
- Sélecteur de démonstration : modèle commune, ville ou département

## Consulter

Ouvrir `index.html` dans un navigateur, ou consulter la version en ligne publiée avec GitHub Pages.

## Avertissement

Les données affichées sont illustratives (noms de villages, fiches, vue aérienne). Elles seront remplacées par les données de la collectivité.
